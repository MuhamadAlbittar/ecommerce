# Multi-Vendor E-Commerce Platform:
A full-featured multi-vendor e-commerce platform built with Laravel. The system enables vendors to manage products, customers to place orders, and administrators to oversee the marketplace through a scalable and maintainable architecture.

# Features:
    #Authentication & Authorization:
        User registration and login
        Role-based access control
        Protected routes and middleware
        JWT Authentication
    
    #Vendor Management:
        Vendor creation and management
        Vendor product ownership
        Vendor dashboard functionality
        
    #Product Management:
        Create, update, delete products
        Product categories
        Product inventory management
        
    #Shopping Experience:
        Product browsing
        Product search and filtering
        Shopping cart functionality
        
    #Order Processing:
        Checkout workflow
        Order creation and management
        Order status tracking
        
    #Shipping System:
        Shipping methods management
        Customer address management
        Shipping calculation support
        
    #Invoice Management:
        Order invoices
        Invoice details and tracking
        
    #Admin Features:
        User management
        Vendor management
        Product moderation
        Order monitoring
